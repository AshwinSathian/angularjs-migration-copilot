# M2.5 — Pipeline Assembler

**Status:** not started
**Depends on:** M1, M2 (after its fix pass)

## Scope

M1's codemods are single-file string transforms. They leave the original `angular.module(...)` registration in place, keep the new class inside the source file's IIFE, and add no imports or `export`. Nothing writes their output into the scaffolded workspace. This milestone closes that gap (docs/decisions.md ADR-058).

- One command runs Stages 0–2 and 4 over a whole repo: inventory, scaffold, apply every applicable codemod per file, emit, verify.
- Emit real Angular files into the target workspace: exported classes, `@angular/*` and RxJS imports, no AngularJS registration code, `.ts` and `.html` names. The source repo stays read-only.
- Run the M2 gate on mechanical output, per file, so one bad file does not reject the rest.
- Write a JSON report: per file, pattern(s) applied, tier, compile log, skip reasons.

## Definition of done

The command has been run against all three fixture repos and its output checked. Mechanical hit rate is reported per repo as files that compile in the workspace over files in scope, alongside the existing match counts, including `blur-admin`. A low number is a valid result.
